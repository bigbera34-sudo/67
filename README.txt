เว็บไซต์สุขสันต์วันเกิดพี่ชาย

วิธีดูเว็บไซต์:
1. แตกไฟล์ ZIP
2. เปิดโฟลเดอร์ birthday_for_brother
3. ดับเบิลคลิก index.html

วิธีนำขึ้น GitHub Pages:
1. สร้าง Repository ใหม่ใน GitHub ตั้งชื่อ เช่น birthday-for-brother
2. เลือก Public และสร้าง Repository
3. อัปโหลด index.html และโฟลเดอร์ images ทั้งโฟลเดอร์ (อย่าอัปโหลดเฉพาะ index.html)
4. ไปที่ Settings > Pages
5. ใน Build and deployment เลือก Deploy from a branch
6. เลือก Branch: main และ Folder: /(root) แล้วกด Save
7. รอสักครู่ แล้วเปิดลิงก์ที่ GitHub Pages แสดงให้

หมายเหตุ: เพลงฝังจาก YouTube ต้องเชื่อมต่ออินเทอร์เน็ต และบางเพลงอาจไม่อนุญาตให้เล่นแบบฝัง
